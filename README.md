# پنل مدیریت کانفیگ 🚀

یک پنل سبک و کامل برای ساخت و مدیریت کانفیگ (VLESS / VMess / Trojan / Shadowsocks).

پنل خودش لینک کانفیگ می‌سازد، حجم و روزهای هر کاربر را حساب می‌کند، سقف مصرف روزانه
می‌گذارد و به هر کاربر یک **لینک اختصاصی** می‌دهد تا خودش مصرفش را ببیند.

روی **Railway** بدون نیاز به VPS و بدون هیچ کامپایل یا بیلد استپ اجرا می‌شود.

---

## ✨ امکانات

**مدیریت کانفیگ**
- ساخت کانفیگ از ۱ روز تا **۳۰ روز** (اسلایدر + اعتبارسنجی سمت سرور)
- حجم از **۲ گیگابایت تا بی‌نهایت** (گزینه «بی‌نهایت» هم دارد)
- **محدودیت مصرف روزانه** (مثلاً ۱ گیگ در روز) که هر شب ساعت ۰۰:۰۰ به وقت تهران صفر می‌شود
- حالت «شروع شمارش روزها از اولین اتصال» (کانفیگ تا اولین استفاده نمی‌سوزد)
- تمدید، صفر کردن مصرف، افزودن حجم، غیرفعال‌سازی، ساخت لینک جدید، حذف
- پشتیبانی از چند سرور برای یک کاربر + امکان افزودن کانفیگ دستی

**آمار (همان چیزی که خواستی)**
- چقدر استفاده کرده / چقدر باقی مانده / درصد مصرف
- چند روز دارد / چند روز مصرف شده / چند روز باقی مانده / تاریخ دقیق انقضا
- مصرف امروز نسبت به سقف روزانه
- آخرین زمان اتصال، تاریخ ساخت، تاریخ انقضا
- نمودار مصرف ۱۴ روز گذشته + آمار کلی پنل
- وضعیت‌ها: فعال، در انتظار اولین اتصال، منقضی، حجم تمام‌شده، سقف روزانه پر، غیرفعال

**لینک اختصاصی کاربر**
- `https://آدرس-پنل/sub/<token>` → لینک اشتراک (Subscription) برای v2rayNG، Nekobox، Streisand، Clash، Hiddify
- `https://آدرس-پنل/u/<token>` → صفحه اختصاصی کاربر با نمودار مصرف، روزهای باقی‌مانده، QR و کانفیگ‌ها
- هدر `Subscription-Userinfo` هم برگردانده می‌شود، پس خود برنامه کاربر حجم و انقضا را نشان می‌دهد

**بقیه**
- پنل کامل فارسی و راست‌به‌چپ، دیت‌به‌صورت SQLite
- API برای ثبت خودکار مصرف از روی سرور
- اسکریپت آماده برای خواندن آمار Xray و فرستادنش به پنل
- خروجی پشتیبان JSON، تغییر رمز، کلید API قابل چرخش

## 🤔 پنل چه کار نمی‌کند؟

پنل **خودش تونل نمی‌زند**. یعنی پروکسی و ترافیک عبوری روی سرور دیگری (VPS یا سرور Xray)
انجام می‌شود و این پنل کارش «مدیریت، حساب‌داری و لینک دادن» است.

مصرف هم از دو راه به پنل می‌رسد:

1. **خودکار:** اسکریپت `scripts/xray_report.py` روی سرور Xray با cron اجرا می‌شود و مصرف را می‌فرستد.
2. **دستی:** از پنل برای هر کاربر حجم مصرفی را دستی وارد یا اصلاح می‌کنی.

اگر حجم تمام شود یا سقف روزانه پر شود یا تاریخ بگذرد، پنل لینک اشتراک را **خالی**
برمی‌گرداند تا برنامه کاربر کانفیگی نگیرد (تا زمانی که تمدیدش کنی).

## 🚂 دیپلوی روی Railway (گام به گام)

### ۱. پروژه را وصل کن
1. برو به <https://railway.app> و با گیت‌هاب وارد شو.
2. **New Project** → **Deploy from GitHub repo** → ریپوی خودت را انتخاب کن.
3. Railway فایل `Dockerfile` را خودش پیدا می‌کند و می‌سازد.

### ۲. 🔴 حتماً Volume بساز (مهم‌ترین قدم)
بدون این کار **همه کاربران و مصرف‌ها با هر دیپلوی پاک می‌شوند**:

1. روی سرویس کلیک کن → تب **Volumes** → **Add Volume**
2. مسیر mount را بگذار: `/data`

پنل به‌صورت پیش‌فرض دیتابیس را در `/data` می‌سازد، پس همین یک قدم کافی است.

### ۳. متغیرها را ست کن
تب **Variables** → **New Variable**:

| متغیر | مقدار نمونه | توضیح |
|---|---|---|
| `ADMIN_USERNAME` | `admin` | نام کاربری مدیر |
| `ADMIN_PASSWORD` | یک رمز طولانی | رمز مدیر (اولین اجرا ساخته می‌شود) |
| `PUBLIC_BASE_URL` | `https://xxx.up.railway.app` | آدرس نهایی پنل، برای ساخت لینک‌ها |
| `ADMIN_PATH` | `panel` | مسیر پنل (برای مخفی‌کردن از اسکنرها عوضش کن) |
| `TZ_NAME` | `Asia/Tehran` | منطقه زمانی برای ریست روزانه |

### ۴. دامنه بساز و باز کن
1. تب **Settings** → **Networking** → **Generate Domain**
2. آدرس را در `PUBLIC_BASE_URL` هم بگذار (همان دامنه).
3. برو به `https://دامنه-تو.up.railway.app/panel`

### ۵. بعد از بالا آمدن
از تب **تنظیمات** پنل:
- **آدرس عمومی پنل** را دقیقاً همان دامنه Railway بگذار (وگرنه لینک کاربران اشتباه می‌شود)
- **کلید API** را بردار و در اسکریپت سرور بگذار

### نکات Railway
- تعداد **Replicas** را روی ۱ نگه دار (SQLite با چند نسخه همزمان سازگار نیست).
- بعد از ست‌کردن `PUBLIC_BASE_URL` یک بار **Redeploy** کن تا مطمئن شوی اعمال شده.
- اگر رمز مدیرت را فراموش کردی، متغیر `ADMIN_PASSWORD_RESET=1` را ست کن، یک بار دیگر دیپلوی کن،
  بعد آن را حذف کن.

| متغیر | پیش‌فرض | توضیح |
|---|---|---|

## 📡 ثبت خودکار مصرف از روی سرور

### الف) ساده با curl

کلید API را از تب **تنظیمات** بردار:

```bash
curl -X POST https://دامنه-تو.up.railway.app/api/report \
  -H "X-API-Key: کلید-API" \
  -H "Content-Type: application/json" \
  -d '{"user":"علی رضایی","used_bytes":1073741824}'
```

فیلد `user` می‌تواند نام کاربر، UUID یا توکن اشتراک باشد.

برای چند کاربر با هم:

```json
{
  "reports": [
    {"user": "علی رضایی", "delta_bytes": 52428800},
    {"user": "محمد احمدی", "used_bytes": 2147483648}
  ]
}
```

- `delta_bytes` = این مقدار به مصرف اضافه شود.
- `used_bytes` = کل مصرف از ابتدا (اگر کمتر از مقدار ثبت‌شده باشد نادیده گرفته می‌شود تا اشتباهی کم نشود).

### ب) خودکار از روی Xray

اسکریپت `scripts/xray_report.py` آمار پنل Xray را می‌خواند و تفاضلش را می‌فرستد.
چون Xray با هر ریستارت شمارنده‌هایش صفر می‌شود، این اسکریپت حالت «تفاضلی» دارد و
ریستارت سرور باعث نمی‌شود مصرفت اشتباه حساب شود.

روی سرور Xray، هر ۵ دقیقه:

```bash
# ذخیره وضعیت
mkdir -p /var/lib

*/5 * * * * PANEL_URL=https://دامنه-تو.up.railway.app \
    PANEL_API_KEY=کلید-API \
    /usr/bin/python3 /opt/panel/scripts/xray_report.py >> /var/log/xray-report.log 2>&1
```

گزینه‌های مهم:

| گزینه | کار |
|---|---|
| `--match name` | ایمیل کاربر در Xray باید دقیقاً نام کاربر در پنل باشد (پیش‌فرض) |
| `--match local` | فقط بخش قبل از `@` مقایسه می‌شود (`ali@vpn` ↔ `ali`) |
| `--mode delta` | تفاضلی و مقاوم به ریستارت (پیش‌فرض) |
| `--mode absolute` | کل مصرف از ابتدا فرستاده می‌شود |
| `--dry-run` | فقط نشان می‌دهد چه چیزی فرستاده می‌شود |
| `--from-file` | به‌جای صدا زدن Xray، از یک فایل JSON بخوان |

## 🔐 امنیت

- رمز مدیر با `scrypt` هش می‌شود، توکن نشست هش‌شده ذخیره می‌شود.
- کوکی نشست `HttpOnly` + `SameSite=Lax` (+ `Secure` روی HTTPS).
- محدودیت تلاش ناموفق ورود و بررسی Origin روی درخواست‌های تغییردهنده.
- هدرهای امنیتی (`X-Frame-Options`, `CSP`, `nosniff`).
- توکن هر کاربر فقط به خودش لینک می‌دهد و توانایی تغییر چیزی را ندارد (فقط مشاهده).

توصیه‌ها:
1. رمز مدیر قوی بگذار و `ADMIN_PATH` را عوض کن.
2. `ENABLE_DOCS=0` کن تا `/docs` خاموش شود.
3. کلید API را جایی امن نگه دار و در صورت لو رفتن از تنظیمات چرخش بده.
4. حتماً از Volume استفاده کن و از دیتابیس بکاپ بگیر (تب تنظیمات → دانلود فایل پشتیبان).

## ❓ عیب‌یابی

**لینک اشتراک خالی برمی‌گردد.**
یعنی وضعیت کاربر فعال نیست. برو در جزئیات کاربر و ببین منقضی شده یا حجمش تمام شده یا
سقف روزانه‌اش پر شده؛ تمدید یا حجم اضافه کن.

**بعد از هر دیپلوی کاربرانم پاک می‌شوند.**
Volume نساخته‌ای یا روی `/data` mount نکرده‌ای.

**لینک‌ها آدرس `localhost` می‌دهند.**
`PUBLIC_BASE_URL` را با دامنه واقعی ست کن، یا در تب تنظیمات «آدرس عمومی پنل» را پر کن.

**مصرف با Xray نمی‌خواند.**
اسکریپت را با `--dry-run` اجرا کن؛ اگر عددی نشان نداد، در Xray آمار (Stats) و ایمیل هر
کلاینت باید فعال باشد.

**صفحه سفید می‌آید.**
کنسول مرورگر را ببین. اگر کوکی را پاک کرده‌ای، سشن منقضی شده و باید دوباره وارد شوی.
